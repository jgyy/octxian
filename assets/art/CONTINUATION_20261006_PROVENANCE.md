# Native continuation paintings · 2026-10-06

These independent location paintings were generated with OpenAI's image_gen tool for Jade Vow. The requested setting and supporting structures were authored for the continuation. Originals are retained as delivered PNG files, without crop, recolor, enlargement or reencoding.

The tool was asked for its maximum supported native landscape resolution. Its actual output is recorded here and in data/world_assets.json; a prompt request for a larger image is not counted as delivered pixels.
